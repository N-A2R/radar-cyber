# Politique de sécurité

Merci de signaler toute vulnérabilité de manière responsable.

## Signaler un problème

Utilisez le signalement privé GitHub: <https://github.com/N-A2R/radar-cyber/security/advisories/new>.
N'incluez **aucune donnée personnelle**, jeton, clé ou extrait de victime dans le rapport.

### Périmètre

- API, front, collecteurs, schéma PostgreSQL, migrations, exports et scripts d'exploitation versionnés.
- Les problèmes de disponibilité sans impact sur la confidentialité, l'intégrité ou l'authentification peuvent être signalés comme issues ordinaires.
- Les tests sur des systèmes tiers ou des données réelles sont hors périmètre.

## Ce que nous demandons

- Une description précise du problème et de son impact.
- Les étapes permettant de le reproduire avec des données synthétiques.
- Un délai raisonnable avant toute divulgation publique.

## Ce que nous nous engageons à faire

- Accuser réception sous 48 heures pour un problème critique, sous 7 jours sinon.
- Fournir un premier plan de confinement sous 72 heures pour un problème critique.
- Corriger ou fournir un plan d'action sous 30 jours pour les problèmes confirmés.
- Créditer le signalleur s'il le souhaite.

Nous ne poursuivrons pas les recherches de bonne foi respectant ce périmètre et n'ayant pas accédé à des données réelles au-delà du nécessaire pour démontrer le problème.

Les signalements sans impact de sécurité démontrable (style, lint, suggestions générales) seront traités comme des issues normales.
