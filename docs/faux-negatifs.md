## Méthode

- Un incident est un **faux négatif** quand la base ne contient aucune ligne pour son URL normalisée ni pour son titre publié le même jour. Les lignes d'`event` et d'`event_archive` sont toutes deux interrogées.
- Pour chaque cas, « ce que la base contenait ce jour-là » est obtenu par agrégation SQL sur `collector_run.started_at`, `event.collected_at`, `event_archive.collected_at` et `observed_at` ramenés au jour UTC ; `observed_at` est la date du fait annoncé par la source, pas la date d'écriture en base, d'où la distinction dans les paragraphes ci-dessous. Un contrôle de déclaration du média est fait dans `source` (`name`, domaine de `url`, `last_ok_at`).
- La fenêtre de collecte observée est **2026-11-13 → 2026-11-21 (bornes incluses)** : toute publication antérieure n'a pas pu être collectée, ce qui est la cause commune des cas ci-dessous. Aucun cas n'est classé « rejeté par le moteur » sur une simple absence.
